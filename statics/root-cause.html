🔍 Root Cause Analysis

In-depth investigation reports with corrective and preventive actions.

INC-004 — Database Connection Pool Exhaustion

Severity
Critical
Root Cause
Connection pool max limit was set to 20 while peak traffic required 80+ concurrent connections. Idle connections were not being recycled due to a misconfigured timeout.
Resolution
Increased pool size to 100, set idle timeout to 30s, and added connection health checks.
Preventive Action
Implemented auto-scaling pool configuration. Added monitoring alerts at 70% pool utilization.
Status
Resolved

INC-002 — API Latency Spike

Severity
Medium
Root Cause
Third-party payment service throttled requests during peak load (12PM–2PM IST), causing response times to exceed 5 seconds.
Resolution
Implemented a fallback response cache and client-side retry with exponential backoff.
Preventive Action
Monthly load testing. Added circuit breaker pattern for all third-party integrations.
Status
Investigating

INC-001 — Database Replication Outage

Severity
High
Root Cause
Misconfigured replication lag threshold (set to 0ms instead of 500ms) triggered a cascading failover across all read replicas simultaneously.
Resolution
Corrected threshold to 500ms. Added automated failover scripts with staggered rollover.
Preventive Action
Quarterly infrastructure configuration audits. Replication lag dashboards with Slack alerts.
Status
Resolved
